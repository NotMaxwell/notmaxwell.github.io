PinnacleCyPat Active

Automated security hardening for CyberPatriot competition images, on both Windows and Linux. It reads the round's own README, applies the mechanical part of the checklist, and reports exactly what it changed. The changes are largely irreversible — deleted files and user accounts, changed passwords, disabled services, a rewritten registry and security policy, uninstalled software — so it ships with a dry-run mode, a desktop GUI over the CLI, and 726 tests.

PING Capstone

Aim the device at something, press the button, and it reports that thing's GPS coordinate. An ESP32-S3 reads a NEO-M9N GPS for its own position, a BNO085 IMU for bearing and elevation, and a TF03 LiDAR for distance, then walks the range out from its own position along that direction on the WGS-84 ellipsoid. Results go to USB serial and a 128×64 OLED.

The repo holds three firmwares: the no_std Rust one that runs on the hardware (esp-hal + Embassy), a C++23 ESP-IDF port written to determine whether sensor dropouts were hardware or code, and an unfinished Zig port. ASCTE class of 2027 group capstone.

Rust no_std Embassy C++23 / ESP-IDF Zig
Repo

PID Cart Controller

Async Rust firmware for a cart-and-rail control lab on a Raspberry Pi Pico (RP2040), using the Embassy framework. The lab ships MicroPython; this reimplements the same loop — read a setpoint potentiometer, measure actual cart position, run the PID, drive the servo command — against the handout's exact formulas, with a C++ version alongside.

Rust Embassy RP2040 PID control

Highway Traffic Simulator

A native Rust desktop app that simulates a highway between two cities in both directions and runs human-driver mode and autonomous mode side by side on identical inputs: same seed, same arrivals, same driver traits, same events. The only difference between the two panes is the controller mix, which is what makes the comparison mean anything.

The default scenario mirrors I-565 from I-65 at Decatur to US 72 in Huntsville: real exits and mileposts, the two-lane work zone between County Line Rd and Wall-Triana, the 65 mph section east of Memorial Parkway, and a morning peak toward Redstone Arsenal and Research Park. Rendered with wgpu; design and deviation notes are in the repo.

GoogleDriveAI

Sorts Google Drive files into class folders with a small neural net trained on the folders already sorted by hand. Docs, Slides, Sheets, PDFs and .docx become text; text becomes a 384-number MiniLM embedding; a 384 → 128 → classes MLP predicts the folder. Training holds out 20% of each class to report honest accuracy, and anything under the confidence threshold is left for a human.

Python Embeddings PyTorch Drive API

Robotics

Lead programmer, lead tester and driver — FRC 10101 Critical Hit and FTC Knockout Robotics

TealTeam Active

The scouting and strategy application FRC team 10101 Critical Hit runs at events. Scouts record what each robot does in each match on wired Chromebooks, the lead scout reviews the forms and builds the pick list, and the drive team reads the numbers on phones from a copy saved while the phone was plugged in. Official results come from the FIRST Events API and The Blue Alliance.

Built for a venue with no internet: a single Linux laptop is the server, running in Docker on a wired network. Rust and axum with Askama templates over SQLite — pages are rendered server-side and work with JavaScript switched off, which is what makes them survive a bad event network.

Rust axum Askama SQLite Docker
Repo

BIOBUZZ Active

Robot code for FTC team Knockout Robotics' 2026–2027 BIOBUZZ season, on the FTC SDK in Java: turret, launcher, intake, transfer and a PedroPathing drive, split into auto, teleop and tuning OpModes.

I built the tuning suite — reusable steps behind one gamepad shell that run a breakaway ramp, a feedforward sweep fitted by least squares, square-wave step response measuring rise, overshoot and settle, sine tracking, and flywheel shot recovery, with gains live-editable from the dashboard and the procedure written up for the team.

Java FTC SDK PedroPathing PID tuning
