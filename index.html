PinnacleCyPat Active

Automated security hardening for CyberPatriot competition images, on both Windows and Linux. It reads the round's own README, applies the mechanical part of the checklist, and reports exactly what it changed. Because the changes are largely irreversible — deleted accounts, rewritten registry and security policy, uninstalled software — it ships with a dry-run mode and 726 tests. Desktop GUI on top of the CLI.

Rust 2024 Windows + Linux Cybersecurity 726 tests
Repo

PING Capstone

Aim the device at something, press the button, and it reports that thing's GPS coordinate. An ESP32-S3 combines a NEO-M9N GPS for its own position, a BNO085 IMU for bearing and elevation, and a TF03 LiDAR for range, then walks that range out along the WGS-84 ellipsoid. Main firmware is no_std Rust on esp-hal and Embassy; a C++23 port exists to isolate sensor dropouts to hardware or code.

Rust no_std Embassy ESP32-S3 Sensor fusion
Repo

Highway Traffic Simulator

A native Rust desktop app that runs human drivers and autonomous control side by side on identical inputs — same seed, same arrivals, same driver traits, same events — so the only difference between the two panes is the controller mix. The default scenario is I-565 from Decatur to Huntsville, with the real exits, the two-lane work zone, and the morning peak toward Redstone Arsenal.

Rust wgpu Simulation
Repo

TealTeam

Scouting and analytics web app for robotics team 10101 Critical Hit. Go and Gin behind server-rendered templates with HTMX fragments, PostgreSQL for storage, and sync against the FIRST and Blue Alliance APIs. Deployed on Render under Docker.

Go HTMX PostgreSQL Docker
Repo

GoogleDriveAI

Sorts Google Drive files into class folders using a small neural net trained on the folders already sorted by hand. Files become text, text becomes a MiniLM embedding, and a 384 → 128 → classes MLP predicts the folder. Anything below the confidence threshold is left alone rather than guessed at.

Python Embeddings Drive API
Repo

CHEmailBot

Outreach to Huntsville-area technology companies from the Chamber of Commerce directory, with a human review step before anything sends and a database-enforced guarantee that no company is contacted twice in a campaign. Bun, Hono and SQLite, with Playwright driving the directory's contact forms and the Gmail API for email.

TypeScript Bun + Hono SQLite Playwright

About

I'm a senior at the Alabama School of Cyber Technology and Engineering in Huntsville, class of 2027. Most of my work sits close to the machine: embedded firmware, security tooling, and simulation, written in Rust when I get the choice and in C, C++, Zig, Go, C# or Python when the platform makes that call for me.

The common thread is projects where being approximately correct isn't good enough — a hardening tool that deletes accounts, a device that has to report the right coordinate, a controller comparison that's only meaningful if both sides get identical inputs. That constraint is the part I find interesting.

  • Systems & embedded: Rust (no_std, Embassy), C, C++, Zig, ESP32 and RP2040
  • Security: Windows and Linux hardening, scripting, CyberPatriot competition
  • Robotics: FTC lead programmer, lead tester and driver; scouting and analytics tooling
  • Web & data: Go, TypeScript, HTMX, PostgreSQL, SQLite, Python
